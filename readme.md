
# Hotel Room Booking System

## Project Description
The Hotel Room Booking System is a Java-based project
designed to manage hotel room reservations and guest details.

## Features
- Room registration and management
- Room availability checking
- Room allocation
- Guest check-in and check-out
- Tariff calculation based on stay duration
- Hotel occupancy reports
- Booking reports

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Date and Time API

## Project Structure
- Room.java - Stores room details
- Guest.java - Stores guest information
- Booking.java - Manages booking details
- Hotel.java - Handles room allocation and check-in/check-out
- Reports.java - Generates occupancy and booking reports
- Main.java - Main program execution

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Navigate to the src folder.
4. Compile the program:

   javac *.java

5. Run the program:

   java Main
